# 任务 1: 简化智能体注册流程

## 问题分析

通过分析 `src/protocol/agentOnboarding.js` 文件，我发现当前智能体注册流程存在以下问题：

1. **加入门槛过高**：
   - 必须提供完整的 `agent_id`（格式严格要求以 ng1 开头）
   - 必须提供 `model` 字段
   - 必须提供 `capabilities` 数组
   - 注册流程复杂，包含多个步骤

2. **验证过于严格**：
   - `validateAgentInfo` 函数要求多个必填字段
   - 缺少默认值处理
   - 错误信息不够友好

3. **网络依赖强**：
   - 注册时默认尝试连接到网络节点（localhost:3000）
   - 网络连接失败时才回退到本地注册
   - 没有明确的离线注册选项

4. **缺少简化注册接口**：
   - 只有复杂的 `onboardAgent` 函数
   - 没有提供一键注册或简化注册的选项
   - 缺少面向开发者的友好 API

## 整改方案

### 1. 添加简化注册函数

**功能描述**：创建一个简化的智能体注册函数，降低加入门槛，自动处理复杂流程。

**实现要求**：
- 函数名：`simplifiedAgentRegister`
- 参数：仅需提供基本智能体信息（如 name、model、capabilities 可选）
- 自动生成 `agent_id`、钱包和握手信号
- 简化验证流程
- 支持离线优先模式
- 提供友好的错误信息

**函数签名**：
```javascript
export async function simplifiedAgentRegister(agentInfo, options = {})
```

### 2. 优化验证逻辑

**功能描述**：改进 `validateAgentInfo` 函数，放宽验证要求，提供默认值。

**实现要求**：
- 允许 `agent_id` 为空（自动生成）
- 为 `model` 提供默认值
- 为 `capabilities` 提供默认空数组
- 改进错误信息，更友好易用

### 3. 增强离线支持

**功能描述**：改进离线注册流程，提供更好的离线支持。

**实现要求**：
- 添加 `offline` 选项，允许明确选择离线模式
- 改进 `fallbackRegisterAgent` 函数，提供更详细的注册信息
- 确保离线注册流程顺畅，减少不必要的网络请求

### 4. 改进错误处理

**功能描述**：提供更友好、更详细的错误信息。

**实现要求**：
- 分类错误类型（验证错误、网络错误、钱包错误等）
- 添加错误代码，便于自动化处理
- 提供清晰的错误信息和解决方案建议

### 5. 添加文档和示例

**功能描述**：改进函数文档，提供简化注册的示例代码。

**实现要求**：
- 为新函数添加详细的 JSDoc 文档
- 提供简化注册的示例代码
- 改进加入指南，包含简化注册的说明

## 验收标准

1. **简化注册函数**：成功添加 `simplifiedAgentRegister` 函数，功能正常
2. **降低门槛**：允许仅提供基本信息即可完成注册
3. **离线支持**：支持明确的离线注册选项
4. **友好错误**：提供清晰友好的错误信息
5. **文档完善**：函数文档详细，包含示例代码
6. **兼容性**：与现有代码保持兼容，不破坏现有功能

## 预期效果

通过实施以上整改方案，智能体注册流程将变得更加简单易用，降低了加入门槛，同时保持了系统的安全性和完整性。这将有助于吸引更多智能体加入 NexusGenesis 生态系统。
